##  How to Run the Code

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the required day's folder:

   ```bash
   cd Day-3-HTTP-FastAPI
   ```

3. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

4. Install the required packages, if a `requirements.txt` file exists:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the Python program or start the FastAPI application according to the day's instructions.
